## Icon URLs

Use `/icon-BODY-EYE[-BACKGROUND].svg` or `.png` with three- or six-digit hex colors (omit the `#`). The eye color also sets the mouth and outline. Leave out the background for a transparent icon.

[View the default mint icon](https://s7a.dev/icon-84c5ad-253538.svg)
